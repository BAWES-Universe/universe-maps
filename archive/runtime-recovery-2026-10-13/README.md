# Recovered runtime backup

Exact recovered runtime bytes and required local assets. Backup preservation only; deployment and live acceptance are not established by this checkpoint.

This checkpoint contains 80 recovered runtime candidates/experiences, 596 original file paths, and 489 distinct original blobs. Relative paths and exact bytes are preserved; identical blobs are reused.

## Scope and limits

- This archive is separate from public/live map paths. It does not select, deploy, approve, or repair a map.
- N01–N50, the latest selected surviving runtime for each of the 12 original template families, two additional Lighthouse experiences, and Reading r4 are included. Any additional recovered variants are identified separately in the catalogue.
- Studio r8 and Reading r4 are retained investigation runtime fixtures. Full original source packages remain unavailable; rendering/live acceptance remains open.
- Keeper’s Return r2 preserves the original runtime, including its known inherited teleport-race issue. Media r7c does not recover the unavailable r9 repairs.
- The 33 H-series originals remain missing. Version/review identities are retained in the catalogue; no reconstructed or unrelated file is presented as an original recovery.
- Original ZIP archives, QA/review images, generation masters, credentials, and unrelated attachments are excluded. Authoring/source records remain in ../source-recovery-2026-10-13/.
- Local file dependencies, hashes, PNG/WAV readability, JSON syntax and JavaScript syntax were checked. Browser, game-engine, visual and multiplayer acceptance were not rerun.

## Restore and verify

Choose a revision in CATALOG.json and copy its entire directory to the intended staging location. Keep every relative path intact. Verify original files against SHA256-MANIFEST.json before using the listed TMJ/WAM entrypoints. Test the candidate in the intended engine before any deployment. Do not treat presence in this archive as live approval.
