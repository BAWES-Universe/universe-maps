# Butterfly Campus v3 · candidate

Import entry: `butterfly-campus.tmj`. Keep `tilesets/` and `scripts/` beside it.

A fuller StudentHub workplace and public student campus, with a quiet gate, fountain, commons, three meeting rooms, classroom, stage/audience, creative/media, research, operations/sales and market.

This folder is self-contained and separate from earlier versions. It has not been published. The map script handles only local scene/roof behavior. Bounded fountain/cascade audio is packaged but stays off until compatible native playback is deployed and accepted. Named areas are prepared for later approved native media and bot setup. A pasted TMJ does not activate WAM meeting or stage properties, create bots, or grant private-room permissions.

Artwork uses native32px world tiles and deliberately scaled individual props. It does not add high-DPI renderer support or sitting animation. Objects are static TMJ layers; individually movable/Y-sorted objects require the native WAM entity route.
