# Reading Conservatory native32 scale study

Supplementary standing-composition study, not a runtime or a seating/movement proof.

The concept background is uniformly shown at 0.5 scale (768 x 512). Eight avatar crops are exact, unchanged 32 x 32 canvases from the retained six-mat r2 compiled transparent proof overlay. No synthetic characters, mirrored frames, avatar scaling or pose edits are used. Their pinned repository frame names, directions and source hashes remain in WOKA-PROOF.json and SCALE-STUDY.json. The source archive's asset notices are retained.

The existing compiled proof input is reused for review, not installed as a character asset or placed in a deployable map. No raw character sheets are distributed. This package includes the complete retained original concept image for deterministic reconstruction of the study, but not a game engine.

Run `python build_study.py` from a directory arranged as in this archive. Pillow is required. The script reads the retained original from ../Reading-Conservatory-r1-concept.png. Source PNG is unchanged. No native route, collision, spawn, foreground-depth, chair occupancy, WAM or live browser/device validation has been performed for this study.
