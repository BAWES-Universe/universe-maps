# Rebuild Timber & Stone Design Studio r2

Install Python3 with Pillow and NumPy, plus Node.js. No online service, key, paid tool or engine modification is required.

1. python tools/build_studio.py
2. node tools/verify_native_routes.cjs timber-design-studio-r2
3. python tools/check_head_geometry.py timber-design-studio-r2

Serve the complete timber-design-studio-r2/map32 directory. The runtime rebuild is byte-exact. Static occupied proofs contain standing reference avatars; no sit action or conferencing integration is implemented.

The original cowork-environment-final.png is the frozen accepted Timber source; build_studio.py preserves the eight upper desks and clears the lower rooms. No new artwork is introduced.
