# Rebuild Timber & Stone Yoga Retreat

Install Python3 with Pillow and NumPy, plus Node.js. No online service, key, paid tool or engine modification is required.

1. python tools/build_yoga.py
2. node tools/verify_native_routes.cjs timber-yoga-retreat-r1
3. python tools/check_head_geometry.py timber-yoga-retreat-r1

Serve the complete timber-yoga-retreat-r1/map32 directory. The runtime rebuild is byte-exact. Static occupied proofs contain standing reference avatars; no yoga animation or sit action is implemented; native broadcast areas are configured but live instructor audio/conferencing is untested.

The original cowork-environment-final.png is the frozen accepted Timber source; build_yoga.py owns the new additive mat, cushion and cubby sprites. Existing tea-table artwork is reused at native scale.
