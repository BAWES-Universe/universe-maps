# Rebuild Timber & Stone Gym

Requires Python3 with Pillow and NumPy and Node.js.

1. python tools/build_gym.py
2. node tools/verify_native_routes.cjs timber-gym-only-r1
3. python tools/check_head_geometry.py timber-gym-only-r1

The bundled original environment raster is compiled unchanged into native32 atlases. No API keys, image generation, paid services or engine modifications are needed for rebuild. Serve the complete map32 directory. WAM native broadcast/conversation areas require editor deployment and remain untested live. Equipment/display are art, not functioning exercise equipment/media.
