# timber-yoga-context-r2

A192px northern continuation of the approved map: complete rear architecture and grounded garden/woodland. No visible functional labels. Every accepted interior pixel, collision cell, seat, target and WAM property is unchanged apart from exact Y+192 translation. All new scenery is blocked. Original atlases are reused byte-for-byte.

Host the complete map32 directory. The native map is48x38tiles at32px,1536x1216pixels. No engine changes, external integrations or publication. Existing WAM meeting/broadcast configuration is preserved, including its permission defaults. No live browser/device or multi-user media test.

Run python tools/build_contexts.py yoga from the source bundle to rebuild. Requires Python3 and Pillow; no network, API or image generation. Native motion verification requires Node.js. Raw avatar sheets are excluded; the preserved occupied proof is a composited image, and runtime contains no avatars.
