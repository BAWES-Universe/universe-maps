Framehouse Film Society / N11-r2

Local authorable map; live play is untested, not published.

Rebuild from this extracted directory:
  python tools/build.py N11
  node tools/native/arrival-audit.cjs N11

Load N11/map32/N11.wam with the complete map32 folder.
Dependencies: Python3, Pillow, Node.js. Native fixture and EasyStar are included.
The source package preserves all original raster assets, compiler, fixture, native source pin, runtime, author proofs and hashes.
Standing frame proofs do not provide sitting animation, automatic facing, gameplay or activity integrations.
