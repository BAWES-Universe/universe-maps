# Riverside Art Fair

Copper glass, rose canvas and indigo gallery along autumn riverbanks

- Local candidate; independent review and live browser/gameplay pending.
- Standing native32 Woka proofs; benches have approach anchors, no sitting animation.
- No live services, automated event, transport or puzzle mechanics configured.
- Areas are editor-ready metadata, with no broadcast/audio configuration.

Host complete map32 folder. Runtime uses native32 orthogonal TMJ and WAM without external dependencies. Rebuild: python tools/build_one.py riverside-art-fair from source archive root. Python3, Pillow, NumPy; Node24 for source-extracted native checks.
