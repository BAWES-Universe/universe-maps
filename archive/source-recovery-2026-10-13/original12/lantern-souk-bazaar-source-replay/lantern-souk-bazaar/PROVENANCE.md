# Provenance

The environment is original project artwork generated with the built-in image generation tool from a task-specific prompt. Master pixels are bundled. No reference artwork was copied and no third-party CC0/public-domain claim is made. Social maps use the project-authored accepted lounge chair and low-table family from the prior flagship source kit, at native proportions without stretching. Media House instead uses newly generated charcoal task chairs at40×45 and contemporary oak tables at80×46, with bundled provenance and native placement records.
