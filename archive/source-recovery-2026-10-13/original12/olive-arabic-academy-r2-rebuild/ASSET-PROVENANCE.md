# Asset provenance

This is a new local candidate bundle; it has not been published. Existing project files were not modified.

- Native detailed timber/stone/plaster, desk, meeting table, olive, plant, fern, couch and cream rug: frozen copies of the user's existing `social-outdoor-office-01/candidate/source/assets` kit. Original artwork was already present in the user's supplied project. No new external asset license is asserted by this bundle.
- Native chair lower/backrail layers, podium lower/upper layers: user's existing `grand-auditorium-01/assets` accepted split-layer furniture. Used at original native size.
- Teal-and-gold rug and low table: user's existing `grand-auditorium-03-foyer-terrace/assets` kit. Rug is assembled by native-resolution nine-slice repetition, not by scaling up a tiny image.
- Reference avatar sprite: existing `grand-auditorium-07-clean/assets/greg-reference.png`. Used in review images only; no player sprite is baked into the runtime map.
- `academy-architectural-kit.png`: new original built-in image-generation result, requested 2026-10-10. Carved sandstone, cedar lattice/window, lesson board, lantern pier and low partition sprites; actual alpha output retained. Selected modules are cropped and downsampled into fixed wall bands. It is an art source, not a complete working map. The compiler builds the real tilemap separately.
- Custom pixel-authored materials, outlines, display artwork and layouts: this bundle's build source. These are decorative; no media or AI service is implied.

No subscription, paid provider signup, API credential, engine patch, repository merge or publication was performed.
