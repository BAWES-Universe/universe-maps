# Asset provenance

- The Astral Concourse architectural shell is original project-generated art, registered to the authored 32px grid.
- Chair and podium pixels are native-size cutouts inherited from the project's original civic-room artwork. Its frozen source manifest describes image generation followed by SVG/Sharp mechanical module rendering at native dimensions. The podium generation master SHA-256 is `a52998c0b41c8e2a3deebd6eea9181bf27234bf432a03bbceb14f19d2bf9c6a4`; the civic architecture master SHA-256 is `06cb1142aa4c17068003889cc9b32a4e30676341ec809d3a7cf542282768a130`.
- The Conference Campus reference informed the three-bank, ten-chair, seven-row seating arrangement. None of its texture atlases is included in this runtime.
- Greg/Woka character imagery was used only for offline scale and occlusion validation. No character sprite is included among the six runtime files.
- The invisible collision texture and map/WAM configuration are project-authored.

This provenance statement does not grant a new standalone asset license or change existing repository licenses. Original generated masters, design sources and reproducible build records are maintained separately from this minimal runtime publication.

The inherited civic artwork is documented in the repository’s [original provenance record](https://github.com/BAWES-Universe/universe-maps/blob/03d83f2/map-mocks/civic-rooms-01/source/provenance.json) and [source README](https://github.com/BAWES-Universe/universe-maps/blob/03d83f2/map-mocks/civic-rooms-01/source/README.md).
