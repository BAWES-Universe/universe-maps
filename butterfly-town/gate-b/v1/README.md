# Gate B: detail to monument

A separate test map. Paste gate.tmj into a new Universe room. Walk north toward the door: framing gradually widens and holds its scale. The ordinary 32px character and original art/collisions are unchanged.

Use the map menu **Play gate music and waterfalls** once for the recovered music and a soft fixed waterfall bed. Native speaker mute, pause, and stop remain available. This is a baked ambient mix, not spatial water. On phones that ignore element volume, use speaker mute or pause; the volume slider may not attenuate, and native Play retry may be required after autoplay is blocked.

**Use my camera** yields to ordinary follow at the current zoom. Reduced motion bypasses the choreography and hides the declared moving visual overlays.

The destination remains blank. Add your own portal at the door using the in-game map editor. This script does not navigate while campusRoomUrl is empty. An optional absolute HTTPS PLAY room URL can be set in that property later; do not use a relative TMJ asset URL.

The 15 image atlases are shared preserved v6 assets with hashes in preserved-assets.json. No existing file is changed by this addition. Standalone cloud Phaser and native-audio tests passed; full Universe mobile acceptance is pending. Desktop final framing has narrow finite side margins. No physical phone test is claimed.
