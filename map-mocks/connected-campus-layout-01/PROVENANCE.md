# Schematic provenance

Original code-native planning diagrams created with Python/Pillow and SVG geometry/text for this project. The diagrams reference the project's own map and painted-study layouts conceptually; no third-party map pixels or assets are embedded. SVGs contain local geometry and text only, without external images, scripts or network dependencies.

Pillow and DejaVu Sans remain under their original licenses. Font software is not redistributed in this folder. The sole archival code change is a relative output directory; delivered PNG/SVG bytes are preserved.
