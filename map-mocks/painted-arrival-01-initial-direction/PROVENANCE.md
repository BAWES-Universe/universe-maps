# Art provenance

The original master was generated for this project with the built-in image-generation tool. The project's own earlier v1 town-arrival and StudentHub-interior images were used as style/material references. No third-party map artwork was imported into this snapshot. The generator returned 1254 × 1254 pixels; the archived native still uses one reduction to 1024 × 1024.

The unchanged existing Greg avatar sheet is included solely to reproduce the 32px scale reference. It is not new avatar art, a map occupant, a configured bot or a general-purpose asset license. Existing rights remain unchanged.

The saved prompt is a historical source record. Its requested six positions differ from the four daily work chairs in the actual output and current direction. This notice records creation history and does not assert exclusivity or guarantee copyright protection for generated imagery.
