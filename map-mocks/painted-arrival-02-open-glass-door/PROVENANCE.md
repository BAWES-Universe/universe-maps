# Painted revision provenance

Original project artwork produced with the built-in image-generation tool. The project's own earlier v1 gate/courtyard studies supplied palette and atmosphere references; no third-party map pixels were copied.

The later edit opens the west glass meeting-room doorway while preserving the initial composition. Separate generation passes provide clean ground, registered alpha objects and original water/glint phases. The exact later tool prompts were not retained, so this record states only the known purpose of those passes. Original output-run identifiers are not needed to use these preserved source files.

Sources are 1254px masters reduced once to a 1024px native target. The final still shows the unchanged 32px Greg avatar only as a scale/depth reference. It does not demonstrate a new sitting animation, dynamic map acceptance, service integration or an account avatar change. Existing avatar rights remain unchanged.

The compiler separates actual painted foreground pixels, low-alpha glazing and canopy shade; collision geometry is independent authoring data. These are source-construction intentions and a frozen composite, not a claim that the final integrated runtime has passed its walkthrough.
