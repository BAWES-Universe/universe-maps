# Brown maquette experiment

Internal composition/material experiment, rejected as the main-world aesthetic before gameplay export. The source is an original Blender scene, with common orthographic scale, actual lighting and physical material joins. It is retained for iteration, not presented as a finished magical map.

The parent review found it too brown and generic, with oversized angular foliage and insufficient painterly richness relative to the accepted gate/v1 atmosphere. Later art development belongs to the parent section folder. No TMJ was exported from this experimental state.

The supplied scene references the original material images under ../../art-source/. It does not use third-party map art or rejected furniture cutouts. Preview is the draft still, not a browser/game screenshot.
