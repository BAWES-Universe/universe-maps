# Artwork provenance

This is original project-generated/authored map art, reused and composed into a separate version. No Conference Campus raster art is copied; that public reference informed spatial/camera mechanics only. No third-party CC0 or other redistribution licence is asserted for generated project artwork.

The accepted chair and podium lineage is recorded in the [original chair generation record](https://github.com/BAWES-Universe/universe-maps/blob/03d83f2/map-mocks/expanded-office-02/source/frozen-review-package/art-meeting/source/generation-record.json) and [civic provenance](https://github.com/BAWES-Universe/universe-maps/blob/03d83f2/map-mocks/civic-rooms-01/source/provenance.json). The new reception master was generated with the built-in image generation tool from an original project prompt, reduced proportionally to192×51, and split with an explicit depth mask. The master, prompt, masks and exact asset hashes are retained in `source/repair-assets` inside the separately delivered full standalone source backup. There is no anisotropic scaling of this counter or the reused casual chairs. The reception marker and widened divider composition are authored code-native overlays.

Greg is the project-authored Greg Gulf-outfit v3, reused byte-for-byte as a native-scale review fixture. No new character artwork was created for this map.
