## B exterior and animation additions

Built-in image generation produced original timber, limestone and four-frame leaf masters. Prompts and masters are included under source in the separately delivered standalone archive. Timber and limestone use uniform 0.5 and 1/3 reductions respectively, then native course crops; no anisotropic scaling. Leaf frames use equal square crops and proportional reduction to 32×32, fixed neutral root pixels and light alpha cleanup. The pavilion reuses the same project-authored chair and low-table assets, unscaled. Raw source furniture/structure alpha is recomposited over new surfaces to avoid old-floor halos; opaque unchanged objects remain exact.

Only map-authored assets and existing native features are used. The named reference informed behavior/layout, not copied artwork. Native animated-tile plugin source remains under its existing upstream licence; no new licence claim is made for project-generated art.

This compact Git package contains runtime assets and review documentation only. Generation masters, prompts, original source assets and rebuild tools referenced above are in the separately delivered standalone source archive identified in README.md.
